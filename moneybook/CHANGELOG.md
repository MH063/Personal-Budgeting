## v1.5.3（2026-10-14）

### 修复问题
- 修复后台静默更新机制的缓存隐患：为 GitHub Releases API 请求添加了时间戳参数及强缓存禁用请求头，彻底解决了缓存导致无法获取最新版本信息的问题。
- 修复编译与类型错误：修正了交易表单及相关组件的类型定义，并利用 SQL CTE 补齐了涉及 `transactions` 查询的大额摊销逻辑，确保统计图表和报表渲染正确无误。

## v1.5.2（2026-10-14）

### 新增功能
- 大额支出分期摊销：在记账表单中新增“大额支出分期摊销”开关与输入框。启用后，底层真实消费流水保持纯净不变，而在所有统计图表、资产趋势及智能分析中，该笔支出会自动按照设定的期数动态平滑分摊至未来连续月份中，避免单月财务图表发生失真突增。

## v1.5.1（2026-10-13）

### 新增功能
- 双进程静默更新机制：彻底告别旧版带有 NSIS 安装进度条的更新模式。新版引入了后台双进程守护逻辑：主程序下载完成绿色更新包（ZIP格式）后，会在后台独立唤起微型更新器，主程序随即退出并释放文件占用。微型更新器将秒级解压覆盖新文件、销毁临时压缩包，并重新拉起新版主程序，全程静默、极速且无感。
- 自动化绿色包分发体系：与静默更新机制相配套，优化了 GitHub Releases 自动发布工作流（CI/CD）。从该版本起，推送到云端的发布产物除了常规的 `.exe` 安装程序外，还将自动打包并上传专用于无痕覆盖的 `moneybook-update-windows.zip` 绿色压缩包。

### 体验优化
- UI全面升级：全方位重构了设置中心及软件界面的视觉风格，引入了现代化 Zinc 色系、全圆角卡片布局及磨砂玻璃半透明（backdropFilter）效果，大幅提升了软件的美观度与交互体验。
- 功能精简与融合：移除了冗余和冲突的功能模块，将“规划”模块相关能力与设置页逻辑深度重组去重，降低了软件复杂度，保持轻量高效。

## v1.5.0（2026-10-12）

### 新增功能
- 预算与现金流规划：新增「规划」页，把年度视角、假设推演与还债计划收在一处——年度预算总览（进度、节奏比、年末外推与逐月对照）、未来 12 个月现金流场景预测（可手改假设，自动标出入不敷出月份与年末结余）、多笔借款偿还模拟（雪球/雪崩两种策略，给出结清顺序、总利息，以及相较「仅最低还款」的节省利息与提前月数）
- 滚动预算策略可配置：可选择是否把上期结余滚入下期，并可设置滚入上限百分比；默认沿用原有行为（结余全额滚入），不改变历史结果
- 导入平台模板：内置支付宝、微信支付、招商/工商/建设/农业/中国/交通/邮储/网商银行、云闪付、京东金融、美团、抖音支付等常见平台的列名约定，导入时自动识别平台并套用列映射，也可在列映射预览中手动切换平台模板
- 借贷分列账单识别：「收入金额/支出金额」「借方发生额/贷方发生额」这类成对列现在可正确拆分方向与金额；「借贷标志」列取值为「借/贷」时也能判定收支方向
- 导入内置归类词典：未开启 AI 也能按常见商户与关键词自动归类（如星巴克归到餐饮、滴滴归到交通），用户自定义归类规则仍然优先
- 导入历史一键补导入：可把历次导入中被跳过的数据一次性汇总还原为待导入行，核对后统一入库

### 修复问题
- 修复借贷分列账单被整行跳过：此前成对的「收入金额/支出金额」只会认领第一列，另一列为空时金额被判为 0 而丢弃整行，现按非空一侧取值并据此判定方向
- 修复「借贷标志」列为「借/贷」时无法判定收支方向、导致该行被跳过的问题

### 体验优化
- 全局搜索升级：命令面板的搜索来源进一步扩展，更多分类、账户与设置分区可直接搜到并一键跳转

## v1.4.0（2026-10-12）

### 新增功能
- 加密账单导入新增 WinZip AES 解密：以 AES-128/192/256（AE-1/AE-2）加密导出的账单，现可直接在本机输入密码解密导入，无需再回导出端改选「明文」重新导出；解密全程离线完成，不上传任何数据
- 命令面板升级为全局效率入口：除页面与交易备注外，现可直接搜索分类、账户与设置项，结果一键跳转到对应管理页或设置分区

### 修复问题

- 修复帮助文档落后于真实导航：帮助中「到账户页」「到收入/支出/转账页」的说明已与当前导航对齐（账户已并入设置，收支转已合并为统一流水页）

### 体验优化
- 修复仪表盘智能建议中警告级别图标显示为异常字符的问题，现显示为正常的警告标识

## v1.3.0（2026-10-07）

### 新增功能
- 智能规则统一中心：归类、商户归并、资金流向、AI 参考知识四类条目汇成一个列表，顶部总览各类条数，支持类型筛选与统一搜索，行内可直接停用/删除，删除即时生效
- 规则文档导入导出：新增人类可读的规则文档格式（每行一条，如「星巴克 => 咖啡」），可下载格式模板、填写后一键导入；同一匹配词再次导入按文档内容覆盖更新，导出始终与当前规则实时同步
- 规则备份包：支持导出/导入 JSON 备份（含停用规则，便于换机迁移与分享），导入按类型合并去重、不覆盖现有规则
- 资金流向判定规则从「导入管理」页迁入「智能规则」页，全部规则一处管理（导入页保留快捷跳转入口）

### 修复问题
- 修复流向规则「分类留空、仅指定账户」时导出再导入字段错位的问题：现保留空位占位，账户不再被误读为分类

### 体验优化
- 规则建立入口唯一化：移除页面内手动添加表单，规则建立统一走「下载模板 → 填写 → 导入文档」，避免多入口造成规则重复与不一致
- 规则文档格式说明与解析行为逐项对齐：流向字段兼容全角竖线、支持双斜线注释行、无法解析的行导入时汇总提示核对、停用状态不受文档重新导入影响
